# 소닉 애니메이션 뷰어 검수 기록

검수일: 2026-10-05. 대상: [sonic_animation_viewer.py](../sonic_animation_viewer.py). 기준: [PRD.md](../PRD.md).

## 환경과 검수 범위

- Windows, Python 3.14.7, pico2d 1.5.1.
- 실제 Windows 창에서 0.3초 실행·렌더링·자동 종료 확인.
- 전체 2회 순환, 시간 경계, 픽셀 대조는 SDL의 `dummy` 비디오 드라이버와 `software` 렌더러에서 검증.
- 종료 이벤트는 SDL 이벤트 큐에 ESC와 창 닫기를 넣어 확인했으며, 수동 마우스 클릭 검수는 수행하지 않았다.
- 테스트 드라이버는 검수 프로세스의 환경 변수로만 지정했다. 프로그램은 일반 실행 시 기본 Windows 드라이버를 사용한다.

## 시간 및 상태 경계 검수

- 마지막 프레임을 표시하는 동안에는 반복 완료 횟수가 증가하지 않는다.
- 5회차 마지막 프레임의 표시 시간이 끝난 뒤 정지가 시작된다.
- 정지 후 다음 동작의 프레임·반복 횟수·상태가 초기화된다.
- 정확한 경계 시간, 여러 경계를 한 번에 넘는 큰 `dt`, 불규칙한 `dt` 입력을 검증했다.
- 전체 2회에 해당하는 시간을 한 번에 입력한 경우와 여러 조각으로 입력한 경우의 최종 상태가 일치한다.
- 1프레임 동작도 5회 표시 시간을 계산한 뒤 1초 정지한다.
- 음수·무한대·NaN 경과 시간은 거부한다.
- `--cycles 0`, `--seconds 0`, `--seconds nan`은 사용법 오류로 종료한다.

## 검수 중 수정한 결함

1. `turn_run` 네 번째 프레임의 위쪽 픽셀 2개 누락을 수정했다.
2. 첫 줄에서 세로 투영 영역이 서로 닿아 이웃 포즈의 작은 픽셀이 포함되던 경계를 연결 영역 분석으로 수정했다. 분리 경계는 x=86, 211, 240이다.
3. 프레임마다 잘린 크기가 달라도 원본 기준선과 몸 기준점을 유지하도록 배치를 보정했다.

[전체 2회 재생 로그](two-cycles.txt)는 인접 포즈 경계의 마지막 좌표 보정 전에 수집했다. 보정 후에도 동작 수·프레임 수·순서·FPS·재생 로직은 동일하며, 최종 좌표로 전체 프레임 렌더링과 시간 경계 검수를 다시 통과했다.

## 재현 명령

저장소 루트에서 일반 Windows 창으로 검수한다.

```powershell
python Labs/LEC09/sonic_animation_viewer.py --trace --cycles 2
python Labs/LEC09/sonic_animation_viewer.py --seconds 3
```

화면이 없는 검수 환경에서는 해당 PowerShell 프로세스에만 SDL 설정을 지정한다.

```powershell
$env:SDL_VIDEODRIVER = 'dummy'
$env:SDL_RENDER_DRIVER = 'software'
python Labs/LEC09/sonic_animation_viewer.py --trace --cycles 2
```

기획 문서 작성 커밋을 제외한 실행 코드 변경 이력:

```powershell
git log --reverse --oneline 53aca89..HEAD -- Labs/LEC09/sonic_animation_viewer.py
```
