## 액션 선정과 원본 렌더링 — 2026-09-29 갱신

원본 전체의 라벨과 호넷 포함 여부를 확인했다. 최신 액션 구성은 [ACTION_CATALOG.md](ACTION_CATALOG.md), 구현 계획은 [PLAN.md](../PLAN.md)에 기록한다.

- 액션은 하나의 동작이고 프레임은 그 동작을 이루는 한 장면이다. 준비·실행·회복을 연결해 한 액션으로 재생한다.
- 최소 4종을 상한으로 삼지 않는다. 지상/공중 변형을 포함한 17개 액션을 대상으로 한다.
- 사용자 지시에 따라 **Flourish와 Counter Attack을 포함**한다. 호넷과 같은 프레임에 그려진 효과도 원본대로 보존한다.
- 호넷이 없는 별도 Effect, Sphere (Ball), Needle/Thread, 가시/파편, Flash는 재생 좌표 목록에서 제외한다. 원본 픽셀은 변경하지 않는다.
- 구현 소스는 `animation_viewer.py` 하나다. 원본 사각형·액션 참조·시간 데이터도 그 파일의 Python 상수로 둔다.
- **이 원본 PNG 자체를 Pico2d의 load_image로 한 번 로딩하고 clip_draw로 필요한 사각형을 직접 표시한다.**
- **액션별·프레임별 PNG, 새 아틀라스, 트림·리사이즈 스프라이트를 생성하지 않는다.** 실행용 이미지 입력은 원본 전체 시트 한 장이다.
- 프레임 수는 육안 계획값이다. 정확한 좌표·기준점·지속 시간·연결은 같은 파일의 원본 clip_draw 검수 모드와 실제 재생으로 확인한다.
- 소스 사각형의 고유 개수와 액션에서의 프레임 참조 수를 구분한다. 원본 주석에 근거한 공유·역순 재사용은 같은 좌표 참조로 표현한다.
- 원본 전체의 실제 Pico2d 로딩과 상·중·하 영역 렌더링은 구현 초기에 확인한다. 현재 설치된 clip_draw의 동작과 좌표 규칙은 확인했으며 창에서의 직접 렌더링은 아직 검증하지 않았다.
