- 명령줄 `--inspect`·`--frame`을 제거하고 실행 중 I 키로 검수/자동 재생을 전환하도록 변경.
- 검수 중 좌/우 프레임 이동, 위/아래 액션 이동, 끝에서 순환하는 동작 유지.

10. 잘못된 좌표·빈 액션·누락 참조·FPS·개별 지속 시간·중복 순서 거부.

## 실제 Pico2d 렌더링

```powershell
python -B Labs/LEC08_Animation/animation_viewer.py --trace --cycles 2
```

원본 전체 2393×13086 이미지를 로딩한 실제 렌더러에서 **2사이클 완료, 정상 종료**했습니다.
추적 출력에서 액션마다 repeat=1..5 → pause → 다음 start 순서를 확인했습니다.

| 관측 지점 | 누적 재생 시간 |
| --- | ---: |
| 첫 Flourish 5회 완료·정지 시작 | 5.833333초 |
| Idle 시작 | 6.833333초 |
| 첫 사이클 완료·Flourish 재시작 | 104.390476초 |
| 두 번째 Wounded 정지 시작 | 207.780952초 |
| 두 번째 사이클 완료 | 208.780952초 |

이 시각은 경과 시간 기반 상태 전환 시각입니다. 실제 화면 표시는 렌더링 주기에 맞춰 갱신됩니다.
스크린샷만으로 정지 시간을 판단하지 않았습니다.

직접 화면 확인:
- 대표 Idle 확대 표시와 원본의 투명도·바늘 끝.
- Counter Attack 5/7 프레임의 넓은 참격 효과와 화면 여백.
- Flourish 9/14 프레임의 흰 궤적과 본체.
- 시트 하단 구간을 사용하는 Wounded 진입 장면.
- 검수 모드의 액션 이동 및 ESC 종료.

모든 장면의 별도 스크린샷을 만들지는 않았습니다.
전체 프레임은 실제 2사이클 재생, 좌표·표시 영역 자동 검사, 아래 원본 픽셀 검사로 확인하고,
대표 및 큰 효과 장면을 화면에서 직접 검수했습니다.
